## 怎么辨别是不是「真住宅 IP」？（自己就能验，别信广告）

1. 连上代理后，查出口 IP：打开 **[ping0.cc](https://ping0.cc)**
2. 看两个值：
   - **IP 类型** = `家庭宽带` / `原生 IP` ✅（`机房 IP` / `IDC` ❌）
   - **风险值** 越低越干净：`10-20%` = 极度纯净，养号安全区
3. 也可查 [ipinfo.io](https://ipinfo.io)、[ip.sb](https://ip.sb) 交叉验证 ISP。

> ⚠️ 提示：ipinfo 有时只显示骨干运营商名（如 AT&T AS7018），要看 ping0 的**深度分类**才准。
