# 节点名里的【3x】是什么意思？——流量倍率避坑指南

买机场 / 住宅 IP 之前，先学会看这一个数字。它决定你实际能用多少流量，而**大部分服务商不会在购买页写它**。

---

## 一句话

节点名前面的 `【3x】`、`[2x]`、`x1.5` 是**流量倍率**：走这条线路时，**跑 1GB 从你的额度里扣 3GB**。

倍率 1.0（或者不标）= 跑 1GB 扣 1GB，这才是 1:1。

## 为什么服务商要设倍率

不是坑人，本身有合理原因：中转线路要额外买一台机器转发，一份流量在中转机上进出各算一次，成本天然高于直连。所以**倍率本身不是问题，不写在购买页才是问题**。

## 算给你看

假设一个套餐标称 **800GB / 月**：

| 你实际用的节点 | 倍率 | 真正能跑多少 |
|---|---|---|
| 直连节点 | 1x | 800 GB |
| 中转节点 | 2x | 400 GB |
| 中转节点 | 3x | **267 GB** |

如果一个套餐的**好线路全部是 3x**，而只有慢的、经常超时的那几条是 1x，那你实际拿到的就是 267GB，不是 800GB。

换算成每 GB 单价，差别是 **3 倍**。

## 怎么自己查（3 步，不用信任何广告）

**第 1 步：看节点名。**
导入订阅后，直接看节点列表。倍率通常写在名字最前面：

```
【3x】中转|日本樱花        ← 3 倍
[2x] 香港 BGP             ← 2 倍
美国 AT&T 家宽 hy2         ← 没标，通常是 1x
```

**第 2 步：如果名字没标，实测。**

1. 打开面板，记下当前「已用流量」
2. 连上要测的那条节点
3. 下载一个**大小已知**的文件（比如 1GB 测试文件）
4. 刷新面板，看已用流量涨了多少

涨 1GB = 1x。涨 3GB = 3x。

> 用 `curl` 更准，因为你能确认下了多少字节：
> ```bash
> curl -o /dev/null -w "实际下载 %{size_download} bytes\n" \
>   https://speed.cloudflare.com/__down?bytes=1000000000
> ```

**第 3 步：换一条不同的节点再测一次。** 同一个套餐里，直连和中转的倍率经常不一样。测一条不代表全部。

## 买之前该问什么

把这三句发给客服，答不上来的自己掂量：

1. 「你们所有节点的流量倍率分别是多少？」
2. 「购买页写的 800GB，是按 1x 算的还是标称额度？」
3. 「哪些节点是 1x？」

## 关于易联（Voguesly）

写这篇不是为了绕回来推销，但既然讲到这里，把我们自己的数据摆出来让你验：

**易联全部节点倍率 = 1.00，没有例外。** 包括所有中转线路（BWG / 日本 / 新加坡 / 香港中转）。

你不用信这句话，导入订阅后按上面第 2 步测一次就知道。节点名里也不会看到任何 `【Nx】` 标记——因为没有。

我们的成本确实是中转贵，但选择用统一定价消化掉，而不是把它变成节点名里一个用户看不懂的数字。
